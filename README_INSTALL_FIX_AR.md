# إصلاح عدم قبول التثبيت على هاتف آخر
السبب: النسخة كانت تُوقَّع بمفتاح debug يتولّد عشوائياً في كل بيئة بناء (GitHub/Klencod)،
فتتعارض مع أي نسخة سابقة مثبّتة على الهاتف الآخر ("لم يتم تثبيت التطبيق").
الحل: مفتاح توقيع ثابت داخل المشروع android/app/blousab-release.jks.b64 (نص Base64 يُفكّ تلقائياً أثناء البناء) مع v1+v2+v3.
- أول مرة فقط: احذف النسخة القديمة من الهاتف الآخر ثم ثبّت الجديدة. بعدها كل التحديثات تُثبَّت فوقها مباشرة.
- احتفظ بنسخة من blousab-release.jks؛ فقدانه يمنع تحديث التطبيق فوق النسخ المثبتة.
- لتغيير كلمات السر: أنشئ android/key.properties (storeFile, storePassword, keyAlias, keyPassword).

## تحديث فوق النسخة القديمة بلا حذف
- versionCode صار يزداد تلقائياً مع كل بناء (دقائق منذ 1970)، فلا يُرفض التحديث كـ"نسخة أقدم".
- التوقيع ثابت (blousab-release.jks.b64). النسخ المبنية بعد هذا الإصلاح تتحدّث فوق بعضها مباشرة.
- النسخة المثبتة حالياً إن كانت من قبل الإصلاح (توقيع مختلف) فاحذفها مرة واحدة فقط، ثم لا حاجة للحذف مجدداً.

## فحص التوقيع في سجل البناء
بعد كل بناء Release يُطبع في السجل سطر [BLOUSAB-VERIFY] فيه نتيجة apksigner وبصمة الشهادة SHA-256.
- إن كانت البصمة نفسها في كل بناء فالتوقيع ثابت.
- إن ظهر ERROR فأرسل صورة هذا الجزء من السجل.
