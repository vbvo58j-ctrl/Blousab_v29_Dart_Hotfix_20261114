# تغييرات هذه النسخة (V27)
لم تُبنَ هذه النسخة ولم تُجرَّب على جهاز (لا Flutter في بيئة التطوير). شغّل `flutter pub get` ثم ابنِ وأصلح أي خطأ يظهر.

- الإشعارات وتعديل الملف الشخصي وكل صفحات الإعدادات بتصميم التطبيق (BlousabPage).
- الوضع النهاري/الليلي: مرشح لوني فوق التطبيق، والصور/الفيديو تُغلَّف بـ BlousabKeepColors.
- أيقونة مستخدم مجهول في البحث عن مستخدمين. شعار B بلا نص + شارة AI.
- QR حقيقي (qr_flutter) وماسح (mobile_scanner) يرسل طلب صداقة.
- القصص: «قصتك» أولاً، دائرة لكل مستخدم، مشاهدات فريدة حقيقية، أسهم معكوسة. التوثيق معطّل.
- الخصوصية: منشورات/قصص (الجميع/الأصدقاء). قائمة المحظورين، حجم نص الواجهة، مفتاح الإشعارات.
- Blousab AI (حقيقي): يُنزَّل Qwen2.5 بصيغة MediaPipe .task من Hugging Face (0.5B ≈ 547MB، و1.5B ≈ 1.6GB) ويُشغَّل محلياً عبر flutter_gemma. يُتحقق من الملف بمقارنة SHA-256 مع بصمة الخادم. مكان الإعداد: `lib/services/blousab_ai_service.dart`.
- الرسائل القصيرة: كل SnackBar استُبدل بـ `BlousabToast` (أيقونة + كلمات قليلة).
