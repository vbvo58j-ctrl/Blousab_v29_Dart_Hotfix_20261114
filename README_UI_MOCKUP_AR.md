# تحديث الواجهات لتطابق التصاميم (Mockup)

تم تعديل **الواجهات فقط** ولم تُمس منطق الاتصال (Bluetooth / Wi-Fi / Mesh) ولا التخزين.

الملفات المعدّلة:
- `lib/widgets/blousab_visuals.dart` : مكوّنات التصميم المشتركة (الشريط العلوي، الجرس، شريط التنقل السفلي، الأفاتار بحلقة نيون، خلفية المحادثة…).
- `lib/main.dart` : الغلاف الرئيسي، شريط التنقل، شاشة الملف الشخصي، شاشة الإعدادات الجديدة.
- `lib/screens/communities_screen.dart` : شاشة المحادثات (أزرار النيون الثلاثة + بطاقات المحادثات).
- `lib/screens/public_feed_screen.dart` : شاشة المنشورات (الفلاتر + بطاقات المنشورات).
- `lib/screens/stories_strip.dart` : شاشة القصص (شريط القصص + بطاقة القصة الكبيرة بالأسهم).
- `lib/screens/chat_screen.dart` : شاشة المحادثة (الترويسة + الفقاعات + شريط الإدخال).

ملاحظات:
- الشاشات الرئيسية داكنة فقط كما في التصاميم.
- الصور الشخصية والبيانات في التصاميم (أحمد الحمامي، سارة…) هي بيانات تجريبية؛ التطبيق يعرض بيانات المستخدمين الحقيقية.
- لم أستطع تشغيل `flutter build` داخل بيئتي (لا يوجد Flutter)، فإذا ظهر خطأ في البناء أرسله لي لأصلحه فوراً.
