# الجزء الخامس — تحديثات الملف الشخصي والحضور والمراسلة
- النصان الترحيبيان قابلان للتعديل من «تعديل الملف الشخصي» ويصلان للآخرين.
- لون التنسيق ووضع الاتصال (بلوتوث/واي فاي) أُلغيا؛ البلوتوث وWi-Fi Aware والشبكة المحلية تعمل معاً تلقائياً.
- نبضة حضور كل 8 ثوانٍ: «متصل/غير متوفر» تحت أسماء الآخرين فقط. وضع الشبح بجانب الجرس.
- صورة المعلّق الحقيقية تصل مع الحضور وتظهر في التعليقات والمنشورات والقصص والمحادثات.
- الضغط على أي صورة أو اسم → ملف المستخدم العام (منشورات، متابعون) بشرط أن يكون متصلاً أو سبق مزامنته.
- زر مراسلة (فقاعة بيضاوية) في المنشورات والقصص: صديق + متصل → محادثة، وإلا رسالة خطأ أو طلب صداقة.
- القلب بدل الإعجاب، حذف المنشور/القصة لصاحبها فقط، عدّاد الإشعارات وعدّاد الرسائل غير المقروءة.
- المنشورات والصور لا تتأثر بالثيم الفاتح، وتقليل التوهج.
- ملاحظة: أندرويد يمنع الموافقة التلقائية على نافذة «الظهور للأجهزة»؛ يُطلب الظهور الدائم مرة واحدة فقط.

# الجزء السادس — مشاركة المنشور والريلز
- «مشاركة» تفتح قائمة الأصدقاء: يُرسل المنشور كاملاً (صورة/فيديو/نص) باسم صاحبه الأصلي مع شريط «شاركه لك فلان — © المنشور الأصلي لـ ...». يُعاد الإرسال تلقائياً لمن كان غير متصل حتى يؤكد الاستلام. يبقى «نسخ النص» خياراً.
- زر مراسلة صاحب المنشور (الأيقونة الرابعة) في المنشورات والريلز.
- ملف المستخدم: زر «إرسال طلب صداقة» (لغير الأصدقاء) + زر «مراسلة».
- الواجهة: زر إضافة منشور صغير أفقي (+) في الجانب، وفي الجانب المقابل أيقونتا «رئيسية / ريلز» بجانب الجرس.
- وضع الريلز: تقليب عمودي كتيك توك، تشغيل تلقائي للفيديو، وأيقونات الإعجاب والتعليق والمشاركة والمراسلة على الجانب، ضغطتان للإعجاب.

# الجزء السابع — التفاعلات والخصوصية
- قائمة المنشور (لصاحبه فقط): «التفاعلات والمشاركات» تفتح شاشة فيها الإعجابات والمشاركات بأسماء أصحابها والتاريخ والوقت.
- الملف الشخصي ← المنشورات: زر «التفاعلات» (كل منشوراتي مع صورة مصغّرة للمنشور في كل تفاعل) وعدّاد إجمالي الإعجابات والمشاركات في الجهة المقابلة.
- خصوصية قبل النشر: الجميع / الأصدقاء / الجميع ما عدا (قائمة أصدقاء)، السماح بالتعليقات، السماح بالمشاركة، إخفاء عدد الإعجابات، وزر «تخطي» للإعدادات الافتراضية.
- ملف الآخرين يعرض منشورات من لديك صلاحية رؤيتها فقط.
